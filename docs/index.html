Your coding agent, on the night shift

Turno runs Claude Code on a schedule on your own PC, on your Claude subscription, a local model or one of 190+ API providers. You watch each run as a live chat, approve the risky steps, and when an account hits its limit the run carries on with the next one.

Download Turno View on GitHub

Free and open source (MIT). Windows and Linux. Needs the claude CLI, signed in.

What it does, on screen

Write the routine once

A routine is a folder with a ROUTINE.md: a prompt, the days and times, the model and what it may do. Fill the form or edit the file; Turno runs it on time and catches up after the PC sleeps.

In the clip: a weekday 02:00 routine in Ask mode, typed in the editor. Sped up 1.8×.

Keep going after the usage limit

Put your accounts in order and add a gateway or API provider at the end. With account pool on, a run that hits the 5-hour or weekly limit continues the same conversation on the next one in line.

In the clip: OmniRoute added as the second entry, under the Claude subscription.

Run it on any model

The same routine runs on your Claude subscription, a local Ollama model, a gateway you already run (OmniRoute, 9router, Claude Code Router) or one of 190+ API providers through a local translator.

In the clip: OmniRoute picked from the catalog, its address filled in for you.

Work next to it

Split terminals, drag tabs into place, reopen any Claude Code, Codex or Gemini session from the sidebar, and pick from ten themes. Turno stays in the tray; closing the window keeps routines running.

In the clip: two splits and a theme change. Sped up 1.6×.

Common questions

For one fire-and-forget job it is enough. Cron skips runs while the machine sleeps, a headless claude ‑p can't stop and ask before a risky tool call, and you can't open a run that is still going and talk to it. Turno adds those, plus locks, account switching and a full log of every run.

Use them if they cover you. Turno keeps each routine as a plain folder you can keep in git, runs the same file on Claude, a local model or a gateway, and adds locks, approval cards and account switching. It can import your Desktop tasks.

It runs the official claude CLI you are signed into, so it uses whatever that sign-in uses, and never handles your token. API or gateway connections only take over when every subscription above them is at its limit.

Settings, Agents and accounts: add a separate Claude sign-in or an API connection and put them in order. Turno only uses accounts you sign into yourself; whether several of your own subscriptions fit your plan's terms is yours to check.

Each routine has a permission mode. In Ask mode a risky step waits for your Allow or Deny, in the app or on your phone, and the run stays paused until you answer. You can also cap steps and time.

Windows and Linux have installers: .exe, AppImage, .deb and .rpm. macOS should work from source but isn't packaged yet.

Give it tonight's shift

Install it, add your first routine and let it run at 02:00. Routines, runs and settings stay on your PC.
