Questions at handover

CronWhy not just cron and claude ‑p?

For one fire-and-forget job it is enough. Cron skips runs while the machine sleeps, a headless claude ‑p cannot stop and ask before a risky tool call, and nothing lets you open a run that is still going and talk to it. Turno adds those, plus locks, account switching and the raw log of every run.

DesktopWhy not Claude Desktop's scheduled tasks?

Use them if they cover you. Turno keeps each routine as a plain folder, runs the same file on Claude, a local Ollama model or a gateway, and adds locks, approval cards and account switching. It can import your Desktop tasks.

BillingDoes it use my subscription or API credits?

It runs the official claude CLI you are signed into, so it uses whatever that sign-in uses. It never handles your sign-in token. API connections are paid by use and only take over when every subscription above them is at its limit.

ModelsCan it run on something other than Claude?

Yes. The same ROUTINE.md runs on a local Ollama model, on a gateway you already run (OmniRoute, 9router, Claude Code Router) or on one of 190+ API providers through a local translator.

AccountsHow do I add a second account to the pool?

Settings › Agents and accounts: add a separate Claude sign-in (each keeps its own folder) or an API or gateway connection, and put them in order. Turno only uses accounts you sign into yourself; whether running several of your own subscriptions fits your plan's terms is yours to check. Details in the README.

SystemsWindows, Linux, macOS?

Windows and Linux have installers (.exe, AppImage, .deb and .rpm). macOS should work from source but is not packaged yet.

SafetyWhat stops it from doing something risky overnight?

Each routine has a permission mode. In Ask mode a risky step waits for your Allow or Deny, in the app or on your phone, and the run stays paused until you answer.
